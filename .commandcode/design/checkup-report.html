// RESOLVED ISSUES
R1 · RESOLVED

Section headings clip under the sticky header on anchor scroll

`.section` / `.ecat-hero` previously got `scroll-margin-top` only inside the ≤480px query, so anchor jumps hid the top ~50px of each title behind the 169px header.

FIXED: base rule `main [id], section[id], .ecat-hero, #catalogMain [id] { scroll-margin-top: calc(var(--header-h) + 12px) }` — responsive via `--header-h`; anchor jump re-verified at 1440 px.
R2 · OWNER DECISION — KEPT

Group-panel slider letterboxes 3:4 portraits in a 16:10 frame

A 4:5 portrait frame trial made the panel exceed the fold on shorter viewports and letterboxed the landscape assets (towels, loungers).

DECISION: reverted to the stable 16:10 frame with `object-fit: contain`; mixed portrait/landscape assets make any single ratio a trade-off — owner prefers no cropping.
R3 · RESOLVED

Header actions overflow at 320 px + 200% zoom

`div.header-actions` and `button.nav-toggle` previously extended past the viewport at 320 px and at zoom-200.

FIXED: ≤480px header lets the brand shrink (`flex: 1 1 auto`, `min-width: 0`, logo `max-width: 100%`); 320 px and 160 px screenshots show logo + FR/EN/TR + nav toggle fully inside.
