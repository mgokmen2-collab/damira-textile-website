# DAMIRA TEXTILE — Katalog indirmeleri

PDF kataloglar bu klasöre eklenir.

- `damira-catalog-2026.pdf` — ana katalog (sitedeki "PDF Kataloğu İndir" bağlantısı bu dosyayı bekler)

## Nasıl eklenir

1. PDF'i bu klasöre `damira-catalog-2026.pdf` adıyla koyun.
2. Ek koleksiyon katalogları için adlandırma: `damira-<collection>-<yil>.pdf` (örn. `damira-monaco-2026.pdf`).
3. Bağlantıyı değiştirmek için: `js/data.js` içindeki `modal.pdf` anahtarının karşılığına `catalogs/<dosya-adı>.pdf` yazın.
